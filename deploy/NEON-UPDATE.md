# KWAZAR: обновление Night Drive

Вариант оформления для существующего сайта на Timeweb в /opt/kwazar-site.

- Основной текст 16–19 px; формы и поля ввода — 16 px. Второстепенные подписи 14–15 px; самые мелкие декоративные метки 11–13 px.
- Локальный Russo One с кириллицей в заголовках; Manrope в описаниях и формах.
- Логотип 300 px на настольном экране, 235 px на узком телефоне. Исходный PNG не изменён.
- Видимое фото автомобиля, световые лучи, синий фон и панели с голубым свечением.
- На телефоне до 540 px — одна карточка товара в ряд; крупные кнопки и формы.
- Ссылки на CSS получили версию, чтобы браузер загрузил новый файл при обычном обновлении страницы.

## Проверки

Браузерные сценарии: ширины 320/390/768/1440 px, меню, поиск, фильтры, избранное, сравнение, галерея, корзина, заявка, кабинет, подтверждение стоимости, ручные цены, сохранение после перезапуска процесса. Ошибок JavaScript нет. Дополнительно осмотрены главная, каталог, форма подбора, контакты и кабинет; ширина 1024 px без горизонтального переполнения. Подтверждены загрузка локального кириллического шрифта и размер описаний карточек 16 px на телефоне и настольном экране.

Скриншоты в deploy/previews. Изменение проверено на локальном Python-сервере. Скрипт установки проверен синтаксически; Docker-сборка и установка на VPS выполняются владельцем в консоли Timeweb. Новая версия ещё не считается установленной до успешного выполнения скрипта и проверки действующего домена.

## Установка

Из консоли существующего сервера:

```bash
git clone --depth 1 --branch update/kwazar-neon-2026-11-07 https://github.com/361361isaisa-hash/kazar-site.git /opt/kwazar-neon-20261107
bash /opt/kwazar-neon-20261107/deploy/install-neon.sh
```

Запускать установку только после успешной загрузки. Если папка уже существует, не удалять её вслепую: проверить, завершилась ли предыдущая установка.

Скрипт проверит текущее приложение, создаст приватную копию файлов, согласованный снимок SQLite и копию файла ключа (если он используется), сохранит образ работающего приложения и команду отката. Копия содержимого /tmp передаётся через docker compose exec tar: docker compose cp для tmpfs здесь не применяется.

Заменяются только index.html, admin.html, order.html, styles.css и два новых файла шрифта/лицензии. Сервер, JavaScript, исходный каталог, товарные фото, .env, .env.runtime, Compose и тома не заменяются. Настройки оплаты не меняются.

При сбое не повторять установку автоматически. Сохранить текст ошибки. Если создан rollback.sh, он возвращает предыдущие HTML/CSS и образ, сохраняя текущую базу и поступившие заявки. Команда его запуска выводится после успешной установки. Не восстанавливать старую базу без отдельной необходимости.

После установки открыть сайт, войти прежним ключом, проверить старые заявки и цены. Секреты и личные заявки не отправлять в чат.
