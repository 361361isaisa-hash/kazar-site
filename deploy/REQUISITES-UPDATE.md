# Страница реквизитов KWAZAR

Страница requisites.html содержит предоставленные владельцем публичные реквизиты ИП и контакты магазина. Адрес нормализован из сообщения владельца. ИНН и ОГРНИП проверены по длине и контрольным цифрам; проверка не заменяет выписку из ЕГРИП.

Добавлены ссылка из подвала сайта, разрешение на выдачу requisites.html в backend и включение страницы в Docker-образ. Товарные данные, фотографии, ключ владельца, настройки оплаты и существующая база не меняются.

Проверено: 18 серверных тестов; выдача страницы и отображение реквизитов на 320/390/1440 px; переход из подвала; отсутствие горизонтального переполнения; запрет выдачи server.py через HTTP. Скрипт установки проверен командой bash -n. Docker-сборка и проверка публичного домена выполняются при установке на Timeweb.

## Установка

В консоли существующего сервера загрузить ветку update/kwazar-requisites-2026-11-07 в отдельную папку и запустить deploy/install-requisites.sh из неё. Скрипт создаёт защищённую резервную копию файлов, SQLite и ключа (если используется файл), сохраняет текущий образ и команду отката. Передача копий /tmp выполняется через docker compose exec tar, поскольку /tmp — tmpfs.

Устанавливаются index.html, styles.css, server.py, Dockerfile, requisites.html. Compose, .env, .env.runtime, каталог, фотографии и тома остаются существующими. Скрипт пересобирает приложение и проверяет /healthz и /requisites.html. Адрес страницы после успешной установки: https://kwazar-led.ru/requisites.html.

Откат возвращает предыдущие index.html, styles.css, server.py, Dockerfile и образ приложения. База и новые заявки не откатываются. Путь к rollback.sh будет выведен после установки. До подтверждённого ответа 200 от действующего сайта ссылка не считается опубликованной.
